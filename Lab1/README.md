- Стабільна версія Python, новіша за 3.13.
- NumPy — робота з масивами та обчислення норм через `numpy.linalg.norm`.
- SciPy — обчислення векторних і рядкових норм через `scipy.linalg.norm`.

## Короткі теоретичні відомості

Для вектора $x = (x_1, \ldots, x_n)$ і $p \ge 1$ норма порядку $p$ визначається формулою:

$$
\|x\|_p = \left(\sum_{i=1}^{n} |x_i|^p\right)^{1/p}.
$$

- **L1:** сума модулів координат.
- **L2:** евклідова довжина вектора.
- **L3:** норма, у якій відносно більший внесок мають координати з більшим модулем.

У програмі NumPy створює відтворюваний набір даних. Далі кожна бібліотека обчислює норми цього самого вектора або рядків матриці. scikit-learn масштабує ознаки за допомогою `MinMaxScaler`; `pairwise_distances` із метрикою `minkowski` обчислює відстань кожного рядка до нульового вектора для заданого параметра `p`.

Норма рядка відносно нуля є лише навчальною оцінкою величини спостереження, а не універсальним алгоритмом виявлення викидів. Результати залежать від масштабу й центрування ознак.
